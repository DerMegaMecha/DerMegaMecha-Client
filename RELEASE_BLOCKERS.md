# Public release blockers

A public release is blocked until the following external facts are supplied and tested:

1. A registered Microsoft OAuth public desktop client ID.
2. Exact official 1.21.1 Fabric release metadata and SHA-512 hashes for all 13 required mods.
3. Official, license-compatible Create and Create: Aeronautics resource packs, or confirmation that none is available and therefore must not be substituted.
4. A Windows 10/11 build host with JDK 21 and WiX/Inno Setup tooling.
5. Real Microsoft/Minecraft account testing.

No setup.exe, mod version, resource pack, or successful launch should be claimed until evidence and Windows execution are available.
