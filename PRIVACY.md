# Privacy

The launcher opens Microsoft sign-in in the user's browser and does not collect or transmit passwords.
Microsoft refresh tokens are protected using Windows DPAPI. Access tokens are kept in memory and are not written to logs.
Minecraft profile names and IDs are used only for legitimate session creation.
Game downloads are requested from Mojang, Microsoft, Modrinth, Forge and Fabric services.
No analytics or telemetry are included.
